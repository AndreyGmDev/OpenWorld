# Mechaxeira

Um jogo acadêmico de exploração e quebra-cabeça em mundo aberto sobre um cangaço futurista

[FOTOS - IMPLEMENTAR]

## Começando

Baixe a iteração mais recente no menu Versões do GitHub para jogar a build lançada.

Siga o passo-a-passo abaixo para desenvolver e testar o jogo em sua própria máquina.

### Pré-requisitos

* Unity 6 (6000.0.35f1, baixe o editor em https://unity.com/releases/editor/archive)
* Git (baixe de www.git-scm.com) ou GitHub Desktop

### Instalação

Clone o projeto em uma pasta de fácil acesso:

```
git clone https://github.com/AndreyGmDev/OpenWorld
```

Abra a Unity Hub;

Abra o projeto de seu disco, que está na pasta anteriormente clonada.
